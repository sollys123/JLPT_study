# JLPT 学习系统 4.1

一套可直接部署到 GitHub Pages 的紫白色日语学习应用。课程日历、每日打卡、法国旅行模式、智能欠课、JMdict English 本地词典和 FSRS-6 词卡复习都在同一个项目里。

## 最快部署

1. 新建一个空 GitHub 仓库。
2. 解压本项目，把解压后的内容上传到仓库根目录。仓库根目录应直接看到 `index.html`、`assets/`、`data/`、`.github/`，不要再多套一层文件夹。
3. 打开仓库 `Settings → Pages`，Source 选择 `GitHub Actions`。
4. 推送后等待 `Deploy GitHub Pages` 工作流完成。
5. 打开 Pages 地址，在 `设置与备份` 中先导出一份完整 JSON 基线备份。

工作流会先运行确定性测试，再下载并校验 JMdict 常用词包和完整例句词包，最后只发布应用文件。词典校验失败时不会带病上线。

本地预览：

```bash
python -m http.server 8000
```

然后打开 `http://localhost:8000/`。长期使用建议部署到 GitHub Pages，不建议一直用 `file://` 双击模式。

### 词典与制卡

- JMdict English 离线安装与本地搜索。
- 自动读取词形、假名、英文义项、词性、常用标记和日英例句。

### Anki 风格 FSRS-6 复习

复习系统不是固定的 1、3、7、30 天表。长期复习间隔由 FSRS-6 的稳定性、难度、可回忆率和目标记忆率计算。

- Again、Hard、Good、Easy 四级反馈；
- New、Learning、Review、Relearning 四种状态；
- 默认目标记忆率 90%；
- 默认学习步骤 1 分钟、10 分钟；
- 默认重学步骤 10 分钟；
- 同源卡当天自动错开；
- 新卡上限、到期复习上限、提前学习窗口和最大间隔；
- 遗忘次数、顽固卡阈值与自动暂停；
- 答案前后状态、复习耗时和完整历史；
- 撤销最近一次复习；
- 评分前预览四个选项的下次间隔；
- 未来 14 天负荷、评分分布、成熟卡与遗忘卡统计。

长期记忆模型使用 FSRS-6 的公开公式和 21 个默认权重；学习步骤严格按 Anki 当前规则处理：第一步按 Hard 时取前两步中点，后续学习步骤按 Hard 时重复当前步骤。实现边界与对照范围见 [`FSRS_AUDIT.md`](FSRS_AUDIT.md)。

推荐初始设置：

- 目标记忆率：90%；
- 每日新卡：10；
- 每日复习上限：9999，不截断已经到期的复习；
- 学习步骤：1,10；
- 重学步骤：10；
- 同源卡错开：开启；
- 顽固卡阈值：8 次遗忘；
- 自动暂停顽固卡：开启；
- Fuzz：默认关闭，保持预测间隔可复现。

除非从可信优化器获得个人参数，不要手动改底层 21 个权重。

### 可选：用个人历史优化 FSRS 参数

刚开始学习时不要优化，保留默认权重。积累较多真实复习记录后，可以用项目内附的官方绑定脚本生成个人参数：

```bash
npm install
npm run optimize-fsrs -- JLPT紫藤完整备份_2027-01-01.json
```

脚本会读取完整 JSON 备份中的复习日志，输出一份包含 21 个权重的 JSON。少于约 400 条有效复习时会给出警告。该工具需要 Node.js 20 以上；网页日常使用不需要安装 Node 或 npm。

## JMdict 数据

项目压缩包默认不塞入几十 MB 的词典数据。部署工作流会下载两个固定版本的数据包并核对 SHA-256：

- 常用词库，适合日常 N4 至 N2 查词；
- 完整例句词库，包含 JMdict English 与例句数据。

网页也支持手动导入 jmdict-simplified 的 `.json.tgz`、`.tar.gz`、`.gz` 或 `.json` 文件。安装后数据进入当前站点的 IndexedDB，后续查词和复习可离线进行。

本地准备词典：

```bash
python tools/fetch_jmdict.py common
python tools/fetch_jmdict.py examples
```

词典内容受 EDRDG/JMdict 与 jmdict-simplified 对应许可约束，详见 [`LICENSES.md`](LICENSES.md)。

## 数据安全

- 日历状态使用当前网站域名下的浏览器存储。
- 词条、卡片、复习日志和词典索引使用 IndexedDB。
- 完整 JSON 备份包含日历、词条、卡片、FSRS 状态与复习日志，不包含可重新安装的大词典。
- 换设备、换浏览器、改 Pages 域名或清理网站数据前，必须导出完整 JSON。
- 当前版本没有跨设备云同步，不会把学习记录上传到第三方服务器。

## 重要边界

- 浏览器朗读使用设备自带的 `SpeechSynthesis`，声音质量取决于系统日语语音。
- 完整例句词典导入时需要一次性解压并建立索引，低内存手机可能比较吃力，建议先在电脑端安装。
- 计划中的 2027-07-04 是当前 N2 排程锚点。官方日期公布后可在设置里修改考试日，但现有逐日任务不会凭空消失。
- 任何软件都不能诚实承诺绝对零缺陷。本项目提供版本固定、数据备份、内置诊断、确定性测试和回归测试，让错误更容易被发现与恢复。
